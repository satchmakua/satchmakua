# Hi, I'm Satchel

I build the tools other engineers build with: test frameworks, release automation and AI dev tooling, mostly in Python.

For 2 years I did that at Synopsys for a chip-design group. These days I'm building open-source tools that check whether AI output is actually right.

**Open to remote work** in dev tooling, test & release automation, or AI tooling. I'm on the Big Island in Hawaii. More about me at [satchelhamilton.com](https://satchelhamilton.com).

## Some things I've built

| Project | What it does | Try it |
|---|---|---|
| [Gatecheck](https://github.com/satchmakua/gatecheck) | A test suite for LLM apps. Grades outputs and fails your build when a prompt or model change makes things worse. | `pip install gatecheck` |
| [Toroid](https://github.com/satchmakua/toroid) | An AI writes formal properties for small RTL designs, and a model checker proves them or shows the exact cycle where the design breaks. | `pip install toroid` |
| [Congruent](https://github.com/satchmakua/congruent-eq) | Proves an AI-rewritten function still does the same thing, or hands back the input that breaks it. | `pip install congruent-eq` |
| [Kinescope](https://github.com/satchmakua/kinescope) | Records an AI agent's run so you can replay it exactly, offline, and fork it at any step. | `pip install kinescope` |
| [Manifold](https://github.com/satchmakua/manifold-cov) | Coverage-driven testing for AI agents. It caught smolagents retrying a dead tool until it burned its whole step budget. | `pip install manifold-cov` |
| [Verderer](https://github.com/satchmakua/verderer) | A tamper-evident record of US government environmental web pages that anyone can check in their browser. | [see it live](https://verderer.satchelhamilton.com) |
